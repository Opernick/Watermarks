# Задание: Затирание невидимых водяных знаков изображений
В этом проекте и исследуются способы скрытого водяного знака и атак на них.  
Студенту необходимо изучить предоставленный код и **реализовать предложенные и собственный методы атаки**.

---

## Установка и запуск

### 1. Установка зависимостей

Рекомендуется использовать Python >= 3.9 и виртуальное окружение

Установите зависимости:

```bash
pip install -r requirements.txt
```

---

### 2. Авторизация в Hugging Face

Модели загружаются из Hugging Face Hub.
Нужно получить Personal Access Token:
 [https://huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)

Создайте переменную окружения:

```bash
export HF_TOKEN="ваш_токен"           # Linux/Mac
setx HF_TOKEN "ваш_токен"             # Windows (PowerShell)
```

После этого выполните вход:

```bash
python huggingface_login.py
```

Если всё успешно — в терминале появится уведомление о входе.

---

## Запуск основных скриптов

### test.py

* Предназначен для **тестирования корректности реализации предложенных методов атак**
* Выполняет запуск и оценку выбранных атак на тестовом наборе изображений и сравнивает с ожидаемой

Запуск:

```bash
python test.py --attacks dip vae --reference-dir ./data/test/results/ --out ./students_summary.json --device cpu
Если --attacks не указан — тестируются все атаки из ATTACKS (в run_single_attack.py).
Если --watermarks указан — тестируются только те, иначе — все доступные WATERMARKS.
```

---

### eval.py

* Выполняет **Запуск и оценку атаки на одном методе вотермаркеринга**
* Запускает **ваши алгоритм атаки на выбранном методе вотермаркеринга**
* Считает метрики качества получаемых изображений (PSNR, LPIPS, VMAF и др.)
* Сохраняет результаты и формирует отчёт по успешности атак

Запуск:

```bash
python eval.py --watermark ARWGAN --attack dip --save-images ./out_images/
```

## Что должен реализовать студент

Для выполнения задания требуется **модифицировать и дописать** следующие файлы:

| Файл                    | Что нужно реализовать                                             |
| ----------------------- | ----------------------------------------------------------------- |
| `vae_attack.py`         | Атака на водяной знак с использованием VAE                        |
| `dip_attack.py`         | Реализация DIP-атаки (Deep Image Prior)                           |
| `adversarial.py`        | Генерация **адверсариальных атак Black-Box** на водяной знак      |
| `feature_extractors.py` | Настройка извлечения признаков                                    |
| `your_attack.py`        | Ваша атака, которая будет оцениваться в рамках соревнования       |

Все эти изменения будут оцениваться в рамках итоговой работы.
